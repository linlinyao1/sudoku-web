# 数独大师 Sudoku

**在线玩：https://linlinyao1.github.io/sudoku-web/**

一个纯静态网页数独游戏，手机和电脑都能玩：`index.html` + `app.js`，无框架、无构建、无联网。

## 玩法

- 9×9 棋盘：点选格子填入数字；下方第一排 `1~9` 填入，第二排 `1~9` 标记候选（可多选）
- 选中数字后，同行/同列/同宫、相同数字、候选中的同数都会分层高亮
- 四档难度按**解题技巧**分级：简单（只用唯一余数）→ 中等（+唯一位置）→ 困难（数对/区块排除）→ 大师（X-Wing、剑鱼、XY-Wing 等高级技巧多次配合）
- 💡 **逻辑提示**：不直接报答案，逐步讲推理过程（共 19 类逻辑技巧），棋盘同步高亮
- 每道题保证唯一解，且全程可用逻辑推理完成

## 运行

直接双击 `index.html`，或起个静态服务：

```bash
python3 -m http.server 8000
```

手机与电脑连同一 Wi-Fi 时，打开 `http://<电脑IP>:8000` 也能玩。
